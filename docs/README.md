# Pokémon Studio documentation

This documentation is the reference for Pokémon Studio: what it does and says, why it works that way, and how it is built. It is written for anyone who [contributes](glossary.md) to Pokémon Studio.

## How to read a page

Each page describes its subject as it is intended to be.

When something is not settled yet, the page flags it next to the subject it concerns, with a note or in a section such as **Open questions** or **Ideas**.

Each page has a status:

| Status | Meaning |
| --- | --- |
| `validated` | The page is a reference: what it states is settled, and what is not is flagged |
| `draft` | The page is not a reference yet: it is still being written, or its subject is still being explored |

## Related resources

Some information about Pokémon Studio lives outside this documentation:

- the [user documentation](https://docs.pokemonworkshop.com), for people who use Pokémon Studio to make a game;
- Figma, for the visual reference of the interface;
- [GitHub issues](https://github.com/PokemonWorkshop/PokemonStudio/issues), for planned and ongoing work.
