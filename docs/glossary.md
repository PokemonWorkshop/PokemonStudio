# Glossary

This glossary defines the common terms of the Pokémon Studio ecosystem. Terms specific to one part of Pokémon Studio are defined in the pages of that part.

| Term | Definition |
| --- | --- |
| Contributor | A person who contributes to Pokémon Studio, whether through its code, its design, its translations, or its documentation |
| Map | A scene of the game, such as a town or a route, where the player moves and events are placed |
| Player | A person who plays a game made with Pokémon Studio. By extension, the character the player controls in the game |
| Pokémon SDK | The game engine that runs the games made with Pokémon Studio |
| Project | A game that a user creates with Pokémon Studio |
| RPG Maker XP | A paid game creation tool. For its place in creating a game with Pokémon Studio, see the [Product vision](design/foundations/vision.md) |
| Ruby | The programming language in which Pokémon SDK is written, and in which users can write scripts |
| Tiled | The open-source map editor that Pokémon Studio works with, and in which users create the maps of their game |
| User | A person who uses Pokémon Studio to create a game. For the main profiles of users, see [Personas](design/foundations/personas.md) |
