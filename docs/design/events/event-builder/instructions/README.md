# Instructions

An instruction is the basic unit of an event's behavior. Each one carries out a precise task, such as moving a character, starting a battle, or checking a condition. Its parameters define exactly what the task involves and how it is performed.

On the canvas, each instruction is represented by a [node](../building-blocks/node.md).

For how to describe an instruction, see the [instruction guidelines](contributing.md).

## Categories

Each instruction belongs to one **category**, which groups instructions around a common theme.

Categories help users find an instruction in the [Instruction Library](../README.md#instruction-library) and recognize it on the canvas by the shared icon and color of its category.

The categories, always presented in this order, are:

1. Game data
2. Game interfaces
3. Battles
4. Flow control
5. Movement
6. Inventory
7. Messages
8. Player interactions
9. Audio
10. Visual effects
11. Start
12. Quests
13. Visual environment
14. Save
15. Scripting
