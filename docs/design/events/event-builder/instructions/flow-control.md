# Flow control

The Flow control category groups the instructions that control when and how events and their [sequences](../visual-scripting.md) run. They shape the logic of a sequence.

## Create loop

> 🚧 **This instruction is still being explored.**

Create loop lets users repeat part of a sequence, indefinitely or a given number of times.

## Exit loop

> 🚧 **This instruction is still being explored.**

Exit loop lets users stop a loop and continue the sequence after the loop.

## Check condition

> 🚧 **This instruction is still being explored.**

Check condition lets users make a sequence follow different paths depending on whether conditions, built in the [Condition Builder](../building-blocks/condition-builder.md), are met.

## Go to label

> 🚧 **This instruction is still being explored.**

Go to label lets users jump to a label, a point that users mark anywhere in the event.

## Wait for duration

> 🚧 **This instruction is still being explored.**

Wait for duration lets users pause a sequence for a given number of seconds.

## Stop event execution

> 🚧 **This instruction is still being explored.**

Stop event execution lets users stop the current event when the sequence reaches the instruction.

## Call event

> 🚧 **This instruction is still being explored.**

Call event lets users run another event from the current sequence, to reuse its behavior.

## Manage event reappearance

> 🚧 **This instruction is still being explored.**

Manage event reappearance lets users erase an event from the map, and control whether it can reappear.
