# Player interactions

The Player interactions category groups the instructions that ask the player for input. The player's answer can then shape what the event does next.

## Wait for key press

> 🚧 **This instruction is still being explored.**

Wait for key press lets users pause a [sequence](../visual-scripting.md) until the player presses a given key.

## Record key press

> 🚧 **This instruction is still being explored.**

Record key press lets users store which key the player presses in a variable, for later instructions to use.

## Input character name

> 🚧 **This instruction is still being explored.**

Input character name lets users ask the player to name a character, including the player's own character.

## Input number

> 🚧 **This instruction is still being explored.**

Input number lets users ask the player for a number between limits that users set, and store it in a variable.

## Ideas

- **Input creature name** could let users ask the player to name a creature.
