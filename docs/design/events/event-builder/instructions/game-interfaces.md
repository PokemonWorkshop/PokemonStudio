# Game interfaces

The Game interfaces category groups the instructions that open the game's menus and screens, or control access to them.

## Open interface

> 🚧 **This instruction is still being explored.**

Open interface lets users open one of the game's built-in menus or screens.

## Open shop

> 🚧 **This instruction is still being explored.**

Open shop lets users open one of the shops, where the player can buy or sell items.

## Manage main menu access

Manage main menu access lets users allow or deny the player access to the main menu, which the player opens during play.

### Parameters

| Parameter | Description |
| --- | --- |
| Access | The change made to the player's access: Allow, Deny, or Toggle (which reverses the current access) |

### Node

From top to bottom, the node's body holds:

1. Access

## Return to title screen

Return to title screen lets users end the current game and bring the player back to the title screen.

Return to title screen has no parameters, and its node has no body.

## Ideas

- **Open custom interface** could let users open a screen created for their own game.
- **Trigger game over** could let users send the player to the game over screen.
- **Open creature shop** could let users open a shop that sells creatures.
