# Battles

The Battles category groups the instructions that start battles and control whether they can happen.

## Start trainer battle

> 🚧 **This instruction is still being explored.**

Start trainer battle lets users start a battle against trainers.

## Start wild encounter

> 🚧 **This instruction is still being explored.**

Start wild encounter lets users start a battle against a wild creature, independently of the map's random encounters.

## Manage random encounters

> 🚧 **This instruction is still being explored.**

Manage random encounters lets users allow or deny wild battles and trainer battles.

## Ideas

- **Start scripted battle** could let users start a battle during which the opposing trainer can talk to the player.
