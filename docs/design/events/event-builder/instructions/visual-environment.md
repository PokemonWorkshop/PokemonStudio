# Visual environment

The Visual environment category groups the instructions that change the ambient visuals of the game, on maps and in battles.

## Change weather

> 🚧 **This instruction is still being explored.**

Change weather lets users change the weather of the current map, such as rain or snow, and its intensity.

## Manage map fog

> 🚧 **This instruction is still being explored.**

Manage map fog lets users cover the current map with a fog image, tinted with a color.

## Manage map panorama

> 🚧 **This instruction is still being explored.**

Manage map panorama lets users change the image behind the map.

## Change battle background

> 🚧 **This instruction is still being explored.**

Change battle background lets users change the background of the battles that follow.
