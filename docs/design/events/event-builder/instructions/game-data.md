# Game data

The Game data category groups the instructions that change the values the game stores and reuses. Events can then read these values to decide what happens.

## Manage variables

> 🚧 **This instruction is still being explored.**

Manage variables lets users change the values of variables, which the whole game shares.

## Manage event variables

> 🚧 **This instruction is still being explored.**

Manage event variables lets users change the values of event variables, which belong to a single event.

## Manage timer

> 🚧 **This instruction is still being explored.**

Manage timer lets users control the game timer, which counts up or down.
