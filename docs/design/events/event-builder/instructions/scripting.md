# Scripting

The Scripting category groups the instructions that run Ruby code written by users. They let users go beyond what other instructions offer, whether to call on a feature of Pokémon SDK or to build a behavior of their own.

## Run script

Run script lets users write Ruby code that runs when the sequence reaches the instruction.

### Parameters

| Parameter | Description |
| --- | --- |
| Script | The Ruby code to run |

### Node

From top to bottom, the node's body holds:
