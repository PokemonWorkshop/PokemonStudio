# Condition Builder

> 🚧 **This subject is still being explored. Nothing on this page is settled.**

The Condition Builder lets users express conditions without writing code. It is a visual tool that guides them toward a valid condition and helps them discover everything they can check.

A condition is a yes-or-no question, such as whether the player has a badge or whether a creature in the party knows a move. Existing projects already use many conditions in their events, and the Condition Builder must be able to express all of them.

What users want to check often involves several conditions at once, which they need to combine into a single answer.
