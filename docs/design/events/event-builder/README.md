# Event Builder

The Event Builder is the workspace for editing an event. Users build what the event does through [visual scripting](visual-scripting.md): they place instructions on a canvas and connect them into sequences, in the order they run.

The Event Builder has three parts, from left to right:

- the **floating panel**, which describes the event;
- the **canvas**, at the center, where each instruction appears as a [node](building-blocks/node.md);
- the **Instruction Library**, a panel that stays open on the right, from which users add instructions to the canvas.

## Pages

> 🚧 **How an event is organized into pages is still being explored.**

An event can be organized into pages, to group its sequences and keep the canvas readable. Unlike the pages of RPG Maker XP, they do not change when or in which order instructions run.

## Floating panel

## Instruction Library

The Instruction Library lists every instruction available in Pokémon Studio, grouped by category.

### Ideas

- The Instruction Library could offer favorites, recently used instructions, and advanced filters.
- Each instruction could have a short description to help users choose the right one.
