# Product vision

Pokémon Studio aims to bring the process of creating a Pokémon fan game into a single application.

Only map creation is entrusted to another open-source tool: [Tiled](https://www.mapeditor.org/), which Pokémon Studio works with directly.

Pokémon Studio is built for a diverse community of [users](personas.md), from people making their first game to experienced developers. Its tools are meant to remain powerful without ever becoming intimidating.

## Direction

Pokémon Studio started as a data editor for Pokémon SDK, the game engine. At present, creating a game still requires RPG Maker XP, a paid tool, notably for events.

Pokémon Studio works to remove that dependency, and the need for any other paid tool. To that end, [event creation](../events/README.md) moves into Pokémon Studio, where it becomes simpler.

Creating a game should also require less and less knowledge of the engine. Pokémon Studio guides users more naturally through the creation of their game, by replacing code and hidden conventions with settings in the interface.
